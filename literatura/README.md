# Literatura

Os artigos que o agente pode consultar para justificar hipóteses. Este índice e
`artigos/` são mantidos por humanos; o agente lê tudo e escreve só em `notas/`.

- `artigos/`: os PDFs, com o nome `AAAA-sobrenome-palavra.pdf`. Ficam só na
  máquina local e não vão para o Git.
- `notas/`: uma nota por artigo, escrita pelo agente quando usar o artigo
  (o que ele afirma, o que vale para TC pulmonar, que tentativa do caderno
  ele motivou).

Entra aqui só o que o agente pode saber. Resultados e conclusões internas do
avaliador ficam de fora enquanto houver uma tarefa de calibração em andamento.

e o que testar a partir dele.
